# MatthiasBenaets Tap

## How do I install these formulae?

`brew install matthiasbenaets/tap/<formula>`

Or `brew tap matthiasbenaets/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "matthiasbenaets/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
